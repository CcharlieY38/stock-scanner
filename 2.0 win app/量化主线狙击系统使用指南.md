
## 🚀 快速开始

### 1. 启动程序

```bash
cd "/Users/charlieyang/stock/stock-scanner/2.0 win app"
python gui2.py
```

或使用启动脚本：

```bash
python start.py
```

### 2. 打开量化主线狙击标签页

- 程序启动后，点击顶部标签栏中的 **"🎯 量化主线狙击"**
- 你会看到三个主要区域：
  - **🎯 主线行业排名 Top 5** - 显示当前市场最强主线
  - **👑 龙头股池 Top 10** - 显示各主线的龙头股票
  - **🎣 超跌反弹候选** - 显示有反弹潜力的超跌股

### 3. 执行盘前扫描

点击左上角的 **"🔍 盘前扫描"** 按钮：

```
🔍 盘前扫描   📡 盘中监控   📥 导出报告
```

系统会自动执行以下步骤：

1. ✅ 识别主线行业（分析各行业强度）
2. ✅ 构建龙头股池（筛选综合龙头和资金龙头）
3. ✅ 识别超跌候选（寻找反弹机会）

### 4. 查看结果

扫描完成后，三个表格会自动填充数据：

#### 主线行业排名表
| 排名 | 行业 | 强度分 | 状态 | 持续天数 | 成分股 | 强势股 |
|------|------|--------|------|----------|--------|--------|
| 1 | 新能源汽车 | 85.2 | 强势主线 | 5天 | 45 | 12 |

- **强度分 > 80**: 强势主线（红色）
- **强度分 60-80**: 新兴主线（黄色）
- **强度分 < 60**: 观察中

#### 龙头股池表
| 代码 | 名称 | 类型 | 所属主线 | 综合评分 | 技术分 | 资金分 | 3日主力流入 |
|------|------|------|----------|----------|--------|--------|-------------|
| 300750 | 宁德时代 | 综合龙头 | 新能源汽车 | 92.5 | 88 | 95 | 5.68亿 |

- **综合龙头**: 技术面+基本面+情绪面综合评分
- **资金龙头**: 近3日主力资金净流入最多

#### 超跌候选表
| 代码 | 名称 | 超跌系数 | 回撤幅度 | 技术背离 | 支撑位 | 当前价 |
|------|------|----------|----------|----------|--------|--------|
| 002415 | 海康威视 | 0.72 | 18.5% | ✅ | ¥42.30 | ¥43.80 |

- **超跌系数 > 0.6**: 值得关注的超跌机会
- **技术背离 ✅**: 价格创新低但指标未创新低，可能反转

### 5. 导出报告

点击 **"📥 导出报告"** 按钮，系统会生成Markdown格式报告：

## 💡 使用建议

### 每日工作流

1. **盘前准备（9:00-9:20）**
   - 打开"🎯 量化主线狙击"标签页
   - 点击"🔍 盘前扫描"
   - 查看主线排名，确定当日市场热点
   - 查看龙头股池，挑选关注标的
   - 查看超跌候选，寻找低吸机会

2. **开盘操作（9:30）**
   - 重点关注主线排名前3的行业
   - 在龙头股池中选择综合评分 > 85 的股票
   - 超跌候选在接近支撑位时考虑买入

3. **盘中监控（10:00-14:30）**
   - 切换到"📈 单只分析"标签页，深度分析个股
   - 使用"📊 批量分析"跟踪自选股

4. **盘后复盘（15:30）**
   - 导出当日报告，记录分析结果
   - 对比实际走势，优化策略

### 选股策略

**稳健型**:
- 选择主线排名 Top 3 的行业
- 龙头股池中综合评分 > 88 的股票
- 持续天数 ≥ 3 的主线（趋势确立）

**激进型**:
- 关注新兴主线（排名2-5，持续天数1-2）
- 超跌候选中系数 > 0.7 且有技术背离的股票
- 资金龙头（3日主力流入 > 3亿）

**价值型**:
- 切换到"📈 单只分析"查看财务指标
- 选择基本面优秀（ROE > 15%, 负债率 < 60%）
- 结合主线位置判断买入时机

## 🎓 技术原理

### 主线识别算法

主线强度 = 0.4×价格动量 + 0.3×资金流向 + 0.2×情绪指数 + 0.1×板块广度

- **价格动量**: 5日平均涨幅
- **资金流向**: 3日主力净流入
- **情绪指数**: 新闻/研报正面情绪占比
- **板块广度**: 强势股数量/总股数

### 龙头筛选标准

**综合龙头** = 0.5×技术分 + 0.3×情绪分 + 0.2×资金分

**资金龙头** = 3日主力净流入排序 Top 5

### 超跌系数计算

超跌系数 = 0.6×回撤幅度 + 0.4×技术背离分

- 回撤幅度：从20日高点的回调百分比
- 技术背离：价格新低但RSI/MACD未新低
