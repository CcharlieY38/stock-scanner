# 🔧 GUI网络问题修复说明

## 📋 问题描述
GUI分析603626时卡在资金流获取环节，原因：
1. ❌ 东方财富API的SSL连接问题
2. ❌ 资金流接口超时（默认6.5秒 × 3次重试 = 19.5秒）
3. ✅ BaoStock数据正常

## ✅ 解决方案

### 方案1：配置文件修复（推荐）

已修改 `config.json`，添加网络配置：

```json
"network": {
    "enable_proxies": false,
    "fund_flow_timeout_seconds": 3.0,      // 减少超时时间
    "fund_flow_retries": 1,                // 减少重试次数
    "skip_fund_flow": true,                // 跳过资金流数据
    "notes": "skip_fund_flow=true 可跳过资金流数据获取，避免超时"
}
```

**现在重启GUI，应该会快很多！**

### 方案2：临时禁用

如果不想修改配置文件，可以运行：

```bash
python start_fixed_gui.py
```

## 💡 为什么会有这些问题？

1. **SSL错误**：
   - 东方财富的HTTPS证书可能有问题
   - macOS的LibreSSL版本较老（2.8.3）
   - urllib3要求OpenSSL 1.1.1+

2. **资金流超时**：
   - 该接口不稳定
   - 不是核心数据
   - 可以安全跳过

3. **代理问题**：
   - 某些环境变量残留
   - 已清理干净
